# CRLVs sinteticos para teste manual

Os tres PDFs desta pasta sao amostras ficticias, marcadas no proprio documento como **SIMULADO - SEM VALIDADE LEGAL**. Eles nao representam documentos oficiais e nao contem dados pessoais reais.

No app, abra **Garagem → Importar CRLV** e selecione um dos arquivos para testar o envio, a extracao pelo Gemini e a tela de revisao. A extracao depende de uma chave Gemini valida e da disponibilidade/cota do provedor.

Arquivos:

- `01-corolla-cross.pdf` — automovel flex, SP.
- `02-civic.pdf` — automovel a gasolina, RJ.
- `03-ranger.pdf` — camionete diesel, MT.

Todos os campos foram criados para teste e podem nao corresponder a registros veiculares reais.
